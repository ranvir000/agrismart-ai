About AgriSmart AI

An AI-powered crop disease detection platform — CSE 7th Semester Major Project

Project Overview

AgriSmart AI is a full-stack web application that uses deep learning (PyTorch MobileNetV2) and transfer learning from the PlantVillage dataset to detect crop diseases from leaf photos. Farmers can upload a photo of any crop leaf, and the system returns a diagnosis, confidence score, severity level, treatment plan, and organic remedies — all in seconds.

🧠 Machine Learning

  • • Architecture: MobileNetV2 (Transfer Learning)
  • • Framework: PyTorch
  • • Dataset: PlantVillage (54,000+ images)
  • • Classes: 38 disease categories
  • • Input: 224×224 RGB leaf images
  • • Preprocessing: ImageNet normalization

⚙️ Technology Stack

  • • Backend: Flask 3.0 + SQLAlchemy
  • • Database: SQLite
  • • Authentication: Flask-Login + Werkzeug
  • • Charts: Chart.js
  • • PDF: fpdf2 (server-side)
  • • Weather: OpenWeatherMap API
  • • Deployment: Render.com
